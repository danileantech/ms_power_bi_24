# Data Storytelling
Its the process to transform raw data into meaningful narrative.
It combines art and science

It presents the data in a form that:
- Captures attention
- Facilitates understanding
- Informs decision making

### Storytelling components
1. Data
2. Context 
3. Narrative

### Storytelling Elements
1. Define the problem (Whats the goal) 
    - Define a clear goal
    - What to expect with the analysis (analysis hypothesis)
    - Set the variables of the analysis
    - Expectations (what message or insight we want to convey)
2. Data Collection and Preparation
    - Collect, clean, transform
    - Merge datasets
    - Remove errors and duplicates
    - Handle missing values
    Output: A well structured dataset and alignement with the goal
3. Data Analysis and exploration
    - Statistical analysis
    - Hypothesis testing
    - Data exploration
    - Patterns and trends
    Outcome: select and extract the critical data that aligns with the goal (key trends, correlations, anomalies)
4. Data vizualization
    - Explore data
    - Communicate data patterns effectively
    - It allows support story goal
    - Requires proper chart type selection
    Outcome: reveal patterns, trends, findings,
            provide context,
            interpret and articulate data
    - Dashboard and reports
5. Audience consideration
    - Consider audience background and knowledge
    - Align with the business requirements
6. Communication
    - Presentations, reports and dashboards
7. Feedback and iteractions
8. Actions and decision making
    - Informed desitions
    - Mantain a narrative
